# Publicar mudanças

1. Ler e seguir integralmente `../publish-without-gh/SKILL.md`.
2. Tratar este comando apenas como um nome curto para esse fluxo; não reduzir suas validações, controles de escopo ou regras de segurança.
3. Preservar a identidade Git já configurada e nunca adicionar autoria, coautoria ou trailers atribuídos à IA.
